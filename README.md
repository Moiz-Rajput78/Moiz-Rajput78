## 🍎 Fruit Detection Using Faster R-CNN

### Computer Vision & Object Detection

A computer vision object-detection system built using **Faster R-CNN with ResNet-50 FPN**.

The model detects, classifies, localizes and counts:

* 🍎 Apples
* 🍌 Bananas
* 🍊 Oranges

The project includes:

* Dataset preparation
* Data augmentation
* Model training
* Validation and testing
* Object detection evaluation
* Performance visualization
* Training-loss analysis
* Robustness testing
* External-image evaluation
* Detection visualization

### Model

**Faster R-CNN + ResNet-50 FPN**

### Reported Results

| Metric            |     Result |
| ----------------- | ---------: |
| Validation mAP@50 | **95.32%** |
| Test mAP@50       | **80.00%** |

## 📄 DocMind — RAG Knowledge Assistant

### Retrieval-Augmented Generation

DocMind is a document-based AI knowledge assistant built around the **Retrieval-Augmented Generation (RAG)** pipeline.

The project explores how documents can be transformed into searchable knowledge and used to provide context-aware answers.

### Key Features

* 📄 PDF, TXT and DOCX document ingestion
* ✂️ Configurable document chunking
* 🧠 Semantic embeddings
* 🔎 Top-K semantic retrieval
* 🗂️ Vector database storage
* 💬 Context-aware question answering
* 📊 Retrieval experiments
* 📈 Evaluation and analysis

### Tech Stack

`Python` `Streamlit` `RAG` `ChromaDB` `Sentence Transformers` `Embeddings` `AI`
